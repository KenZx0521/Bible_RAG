# 聖經問答 demo

問一個聖經問題，看答案、核對經文，好奇時看一眼答案怎麼找到的。零安裝、無 build step。

```bash
cd frontend && node server.mjs   # 開 http://127.0.0.1:5173（Node 18 以上）
```

需要 staging backend（`:8002`）與 Neo4j 在跑。

## 環境變數

| 變數 | 預設 | 說明 |
|------|------|------|
| `DEMO_HOST` | `127.0.0.1` | 綁定位址 |
| `DEMO_PORT` | `5173` | 埠號 |
| `DEMO_ALLOWED_HOSTS` | 空 | 逗號分隔的網域白名單，用網域連才要設；IP 與 `localhost` 不必列。沒列的網域一律 403，用來擋 DNS rebinding |
| `DEMO_BACKEND_URL` | `http://localhost:8002` | backend（staging r12） |
| `NEO4J_HTTP_URL` | `http://127.0.0.1:7474/db/neo4j/query/v2` | Neo4j Query API，只送唯讀查詢 |
| `NEO4J_USER`、`NEO4J_PASSWORD` | 讀 repo 根目錄 `.env` | 只留在 server，不會送到瀏覽器；讀不到時答案照常，只是沒有關聯圖 |

## 從遠端主機看

server 只綁本機，用 SSH 轉埠，再開瀏覽器到 `http://localhost:5173`：

```bash
ssh -L 5173:127.0.0.1:5173 <遠端主機>
```

## 圖上畫什麼

圖上只畫圖譜真正走到的段落（`kg.passages[].walked`），否則讀者會以為經文全是圖譜找到的。沒走到但有事件對應的段落也畫，但只有事件那條線（事件對應是查表，不是走圖），卡片左側有一條墨線區分。其餘沒走到的段落不進圖，精簡與完整都一樣；它們仍在經文來源裡，圖下方會寫「另有 N 段是直接比對問題找到的，沒有經過圖譜」。

畫面上的「答案參考的段落」指這段有交給模型（在 `sources` 裡），不代表答案一定引用它，所以不寫「答案用到」。說明裡的段數等於精簡圖上走到且用到的卡片數，由測試對五份 fixture 驗證。親屬卡帶進來的出處不是直接比對找到的，句子會分開講（`found_by` 只有 `kin_evidence`）。走了但沒用到時不畫空框，只留說明與「顯示完整圖譜」。

卡片標的範圍就是點開看得到的範圍：段落只有 chunk 來源時標 chunk 的範圍；來源比段落大（章節區塊）時標段落的範圍，點開高亮那幾節。

## 圖怎麼剪枝

親屬圖與段落全用到的小圖（節點 ≤ 14 且邊 ≤ 24）不動。走圖圖再小，精簡圖也只留「走到且用到」與事件對應的段落。名字以「連到幾段 × 罕見程度」計分：問題裡的名字一定留，其他名字要能串起兩段以上才有資格，取前 8 個，每段最多 4 條邊，再視需要藏到總量內；事件一律留。走到且用到的段落一定留：名字都被藏光時補回一個，這條優先於總量上限。親屬圖超量時從問題問的人往外，近的優先。被藏的不會靜默消失：畫面會寫「為了好讀，隱藏了 N 個人名地名、M 段經文」，並提供「顯示完整圖譜」。實作在 `public/js/prune.js`。

## 已知限制

- 只有 staging 有圖譜；prod（`:8000`）沒有，指過去會沒有關聯圖。
- 年表卡與年歲卡只顯示推算文字、不畫圖，因為回應裡的鏈節點只有代號沒有名字。
- 這是 demo，不是正式部署：沒有登入、沒有 HTTPS，限流在 server 記憶體裡，重啟就歸零。
- 一題通常要 12–30 秒，機器忙時實測到 50 秒；同時最多問 2 題，每個 IP 每分鐘 20 題。
- 連線數：每個 IP 最多 64 條、全部最多 1024 條，超過直接關。SSH 轉埠時所有人都算同一個 IP，約夠十個瀏覽器。慢連線：標頭沒送完（包括連上後什麼都不送）10–12 秒、請求沒送完 30–32 秒就關（常數加 2 秒檢查週期，實測 12.0／32.0 秒）；請求送完、等回應時的閒置上限是 200 秒。被大量連線轟炸時，接受再關閉本身仍會吃 CPU 與暫時的記憶體（2 萬條實測尖峰約 130MB）；真要對外請放在反向代理後面。
- backend 不會因為客戶端斷線而停止生成（實測 vLLM 記的是 stop 不是 abort），所以按「換一個問題」後，舊題目仍佔額度到跑完為止；新題目此時會排隊等它，不會收到 429。排隊最多 2 席、每個 IP 一席、最久等 60 秒。

## 測試

```bash
pnpm install --offline || pnpm install   # 只有 e2e 要 Playwright
pnpm test                                # 純函式與 server
pnpm test:e2e                            # 瀏覽器流程，/api/ask 接到 test/fixtures，不打真後端
SHOTS_DIR=/tmp/shots node test/e2e/shots.mjs   # 截四個寬度的主要畫面，人工檢查用
```
