# paper/record — 論文發現要點紀錄

**用途**:累積可直接轉寫進最終論文的「發現(findings)層級」素材。與 `docs/` 的執行紀錄分工:docs 記「做了什麼、怎麼做」,這裡記「發現了什麼、怎麼寫進論文」。

**慣例**:
- 檔名 `YYYY-MM-DD_主題.md`,一份紀錄對應一輪分析或實驗結論
- 每條發現附:主張(一句話)、量化證據與出處(檔案/數據目錄)、建議章節、文獻掛鉤
- 引用陷阱(查證過不可引的說法)隨相關發現一併記錄,避免寫作期誤引
